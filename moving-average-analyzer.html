How to Use This Tool

1. Click "Choose CSV Files" to select one or more CSV files

2. Select symbol, time range and moving average periods

3. Click "Analyze Data" to start the analysis process

4. After analysis is complete, click "Export Crossovers" to download CSV file

5. Use "Reset" to clear all files and start over

What CSV formats does this tool support?+
The tool supports standard CSV format. Expected headers: Date, Open, High, Low, Close, Volume, Symbol.
Is there a file size limit?+
The current limit is 10MB per file. For larger files, consider splitting your data.
How are moving averages calculated?+
Simple Moving Average (SMA) = average of last n Close values.
